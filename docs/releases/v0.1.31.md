# Pasteory 0.1.31 Beta

- English is now the default on first launch. Switch instantly between English and Simplified Chinese in Settings → General → Interface Language; your choice is remembered.
- The Quick Panel, Library, Settings, menus, dialogs, update prompts, and Chrome extension popup support both languages. Clipboard content, titles, notes, and custom groups keep their original text.
- The English README now focuses on everyday use, links to a Chinese version, and includes new Quick Panel and Library screenshots in both languages.
- The Library lives in a larger, resizable Settings window. ⌘L opens the Library; ⌘, opens General.
- Daily update checks and an independently colored Update ↓ button let you review release notes before confirming a GitHub download, verification, installation, and restart.

Requires macOS 14 or later and Apple Silicon. Versions 0.1.29 and earlier need one manual installation to gain the updater.

- 首次启动默认英文，可在“设置 → 通用 → 界面语言”即时切换简体中文 / English，并记住选择。
- 快捷面板、资料库、设置、菜单、弹窗、更新提示和 Chrome 插件弹窗均支持两种语言。剪贴板内容、标题、备注和自定义分组保留原文。
- README 默认英文并提供中文入口，补充两种语言的快捷面板和资料库截图，专注日常使用。
- 资料库位于更大的可缩放设置窗口，⌘L 定位资料库，⌘, 打开通用设置。
- 每日检查更新，发现新版时显示独立配色的“更新 ↓”，查看说明并确认后才从 GitHub 下载、校验、安装和重启。

需要 macOS 14 或更高版本及 Apple Silicon。0.1.29 及更早版本需先手动安装一次，才具备应用内更新能力。
