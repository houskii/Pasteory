# Pasteory 0.1.48 Beta

- 最近内容 Top N 改为每次调整 100 条，范围为 100～1,000 条。
- 分析策略默认全部开启。旧配置升级时迁移一次；之后手动关闭的选项保持用户选择。保留模型、主题数量、预算和结果应用方式。
- 新增内容使用独立文件任务，只提供排队的新资料与现有分组信息，优先补充分组，不覆盖已有分组概况。最近调用按任务归并，可展开模型调用并查看对应任务资料。
- 链接解析改为按具体链接统计和展示，按最近解析日期分组，支持日期、状态和搜索筛选。显示采集应用、网站、收录时间、最近尝试、上次成功、解析方式、HTTP 状态和耗时；失败后保留旧标题时明确提示。
- 生命周期与 AI 统一使用“活跃度”。内容详情与分组概况显示“活跃度前 XX%”，同分并列；资料库和快捷面板的 AI 分组显示综合活跃度。排名和分组分值在后台计算并复用缓存。

适用于 Apple Silicon，macOS 14 及以上。

本次按用户要求只发布，不替换构建 Mac 上已安装的 Pasteory。

本地安装包使用本机生成的 Pasteory Local Build 证书签名，该证书不是 Apple 颁发的开发者证书。安装包未经过 Apple 公证。

本版本提供 GitHub Release 手动安装包和 SHA-256 校验文件。本机缺少原 Sparkle 更新私钥，GitHub 发布环境也未配置恢复私钥，因此未更新应用内索引，且未替换客户端已信任的更新公钥。现有 0.1.47 的“检查更新”不会检测到本版本；应用内升级链路尚未恢复，不能将本次安装包发布视为自动升级验收通过。
