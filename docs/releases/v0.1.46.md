# Pasteory 0.1.46 Beta

- AI 整理改为完整文件任务：全部选定资料集中在一个 JSON，由 Agent 自行读取、检索和生成方案，取消应用侧抽样与逐批分类。
- 图片和文件引用原路径，支持按需读取；新增原资源读取开关，不再将图片资源重复复制到任务目录。
- 主题数量由资料决定，移除正式文件任务的 8 组上限。旧草稿仅作参考，校验新建组与已有组的引用，防止错误复用草稿 ID。
- 保存任务目录、会话和中间结果，支持暂停继续；分析期间变化的条目单独跳过并重新入队，其余结果保留。
- 存储看板新增“AI 任务历史”，保留 Prompt、输入、方案、执行记录和模型实际用量。
- 更新 AI 整理设置与状态提示，保留当前模型和推理强度设置，整理方案仍先预览、支持撤销。

适用于 Apple Silicon，macOS 14 及以上。

此 Beta 使用构建 Mac 本地生成的开发代码签名证书，该证书不是 Apple 颁发的开发者证书。安装包未经过 Apple 公证。

本版本通过 GitHub Release 提供手动安装包和 SHA-256 校验文件。本机构建环境缺少原有 Sparkle 更新私钥，因此不更新应用内自动更新索引，也不替换客户端已信任的更新公钥。
