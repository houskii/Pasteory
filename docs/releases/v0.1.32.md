# Pasteory 0.1.32 Beta

- 合入 AI 整理功能：连接本机 Magpie 或兼容模型接口，按主题提出分组建议，并在应用前预览具体变更。
- 支持带原文引用的归纳、固定成员的资料聚合、可恢复的分批任务，以及每日 token 预算和用量记录。
- 最近内容的分析范围扩大到 Top 1000，每批最多 100 条，默认每批 50 条。
- 保留用户编写的备注、主题定义和手动分组关系。AI 分析和自动压缩默认关闭。
- 包含远端主分支的更新检查和首次启动辅助工具改进。

需要 Apple Silicon 和 macOS 14 或更高版本。此 Beta 使用稳定的本地开发签名，尚未经过 Apple 公证。
