# Pasteory 0.1.49 Beta

- 恢复 Sparkle 更新发布：建立新更新密钥、加密恢复包和 GitHub Actions Secret，后续发布无需依赖当前 Mac。
- 发布前验证固定公钥是否能核验真实签名，提前发现私钥缺失或公私钥不匹配。
- 增加独立的 GitHub 签名恢复验证流程，检查云端能否解密恢复并使用原签名身份。
- 补充换机、密钥备份和恢复步骤。

**这次需要手动安装一次。** 原更新私钥和原恢复私钥无法找回，本版本按用户确认的方案更换更新公钥。0.1.48 及更早版本需要从本 Release 下载 DMG 手动安装；安装此版本后，后续更新继续通过应用内“检查更新”验签、下载和安装。

适用于 Apple Silicon，macOS 14 及以上。保留原应用代码签名身份。

本次按用户要求只发布，不替换构建 Mac 上已安装的 Pasteory。

安装包使用本机生成的 Pasteory Local Build 证书签名，该证书不是 Apple 颁发的开发者证书。安装包未经过 Apple 公证。
