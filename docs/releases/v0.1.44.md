# Pasteory Beta 0.1.44 (49)

- 修复文字预览在异步加载完成后覆盖用户所选显示方式的问题。手动选择 Markdown 或原文后，不再被自动识别结果改回；普通文本补充两种模式可能相同的说明。
- 补齐文字预览窗口的 Command-W 关闭支持，关闭按钮、Escape 和窗口关闭按钮使用同一关闭流程，关闭后可再次打开。
- “打开方式 → 图片”支持选择图片打开应用，可使用预览、Chrome 或其他本机应用。未选择时沿用预览，打开时保留原始图片文件内容。
- 补齐 OCR 和 AI 分组设置的英文文案，通过多语言完整性检查。

安装包为 Apple Silicon Release 构建，使用本机生成的 Pasteory Local Build 证书签名，未经过 Apple 公证。

本版本通过 GitHub Release 提供手动安装包和 SHA-256 校验文件。由于本机构建环境缺少已发布版本的 Sparkle 更新私钥，本次不更新应用内自动更新索引；继续保留客户端已信任的更新公钥。
