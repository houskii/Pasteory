# Pasteory 0.1.57 Beta

- 图片来源图标加上主题色描边。快捷面板的图片卡片缩小缩略图和留白，识别文字最多显示三行。
- HTML 与图片等混合剪贴板使用同一套图片卡片布局，保留项目数，图片规格和 OCR 与时间戳分行对齐。
- 已有 Story 的格式更新和定期更新都在设备空闲后开始。打开 Story 会显示保存的回顾。
- Agent 按整个请求的大小计算输入预算，自动略过较早的对话轮次。原资料、工具结果和已保存的任务进度可继续读取。

适用于 Apple Silicon，macOS 14 及以上。沿用现有的应用签名身份和 Sparkle 更新密钥。

安装包使用本机生成的 Pasteory Local Build 证书签名，未经过 Apple 公证。
