# Pasteory Beta 0.1.42 (47)

- 重新整理默认可按最近 Top N（最高 1000 条）重新规划主题，包含未分组内容。所选组现有成员数不再被误解为 Top N 范围。仍可单独选择仅重分所选组或全库；替换旧组前明确显示范围外成员的去向，方案先检查、应用可撤销。
- 应用生命周期内共享 Repository 与轻量元数据缓存。首次后台加载后按数据库提交的版本接收增删改，重复打开面板和管理页不重新读取全库；分组改名只更新受影响的搜索项。
- 新增默认关闭的 OCR 开关，可选择 macOS Vision 准确模式（中英文）或快速模式（英文等西文）。开启后仅后台处理新入库的图片，不补扫历史记录或重复复制的已有图片；未完成的新任务可在下次启动继续。
- 识别成功后在图片备注末尾追加 `[OCR:识别文字]`，原备注和 OCR 内容均可手动编辑，修改后同步用于搜索。空结果不写备注，也会缓存。图片字节与复制时间保持不变。
- AI 分析策略新增“使用图片的本地 OCR 文字”，默认关闭。开启后只发送识别文字，不发送图片文件；已识别的密钥仍被排除。

安装包为 Apple Silicon Release 构建，使用本机生成的 Pasteory Local Build 证书签名，未经过 Apple 公证。应用更新仍需用户确认后才下载安装。
