# Pasteory Beta 0.1.45 (50)

- 修复一条资料变化导致整批 AI 整理无法继续的问题。保留其他已完成结果，将变化的资料按最新版本重新入队，删除或禁止分析的资料则跳过。
- 恢复旧版因“Content changed”暂停的任务，保留原任务及分析范围，不因恢复任务加入新复制的无关资料。启动时修复保存的队列，继续分析仍由用户发起。
- 每批分析之间检查资料版本，移除引用旧资料的分组操作及关联结果；只有受影响的资料需要补算。持续变化的资料留待后续任务，其余内容继续整理。
- 删除单条资料不再清掉整份未完成的分析进度。状态栏会显示补算和跳过的数量。

安装包为 Apple Silicon Release 构建，使用本机生成的 Pasteory Local Build 证书签名，未经过 Apple 公证。

本版本通过 GitHub Release 提供手动安装包和 SHA-256 校验文件。本机构建环境缺少原有 Sparkle 更新私钥，因此不更新应用内自动更新索引，也不替换客户端已信任的更新公钥。
