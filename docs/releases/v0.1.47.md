# Pasteory 0.1.47 Beta

- 修复文件 Agent 忽略已保存主题数量设置的问题。恢复目标 6～8 个、最多 8 个主题的设置入口，任务 Prompt、清单、输出 Schema 和结果校验同步遵守此设置。
- 整理预览改为展示一份方案中的各个分组，显示实际组数、归类数和未分组数。同一组的新建、添加成员和更新概况合并展示，避免把 42 项底层操作误解为 42 个分组。
- 超过组数上限的旧方案保留供对照，并在应用前拦截。可点击“继续修正这份方案”，在原任务目录、原资料范围和同一 Agent 会话中继续修正；原方案会归档。
- Agent 继续自主读取完整 JSON、检索资料和选择工具；分组数量遵守用户设置。原文、备注、手动文件夹和已有资料保持不变。

适用于 Apple Silicon，macOS 14 及以上。

安装包使用本机生成的 Pasteory Local Build 证书签名，该证书不是 Apple 颁发的开发者证书。安装包未经过 Apple 公证。

本版本通过 GitHub Release 提供手动安装包和 SHA-256 校验文件。本机构建环境缺少原有 Sparkle 更新私钥，因此不更新应用内自动更新索引，也不替换客户端已信任的更新公钥。
