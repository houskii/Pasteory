# Pasteory 0.1.40 Beta

- 快捷面板先补读尚未处理的剪贴板，再准备首屏和选中位置后显示，避免刚复制就打开时先显示旧列表、随后跳动。资料库刷新与链接解析放到后台，不阻塞本次打开。
- 快捷面板和资料库默认先加载 100 条，滚动到底部继续加载；键盘接近已加载列表末尾时也会预加载。翻页保留选中项，切换分组视图后恢复原有阅读位置。
- 搜索在整个数据库中匹配并在后台排序，按页显示结果；移除旧的 2,000 条全文检索候选限制。首屏数量不限制搜索范围，规则分组也会检查全部候选内容。
- 滚动位置不再触发所有卡片重画；每条搜索结果的相关度只计算一次。调整卡片文字区域的高度计算，使正文和时间信息垂直居中。
- 主界面持续显示整理进度、暂停或失败原因，并提供“继续整理”和“放弃任务”。再次发起整理时会明确提示已有任务，避免只返回英文错误或看起来没有反应。
- 未完成任务的错误会随进度保存，重开应用后仍可查看。主题规划返回无效方案时，最多要求模型修正两次，每次均计入原有用量预算；方案仍需检查后应用。

适用于 macOS 14 及以上的 Apple Silicon Mac。使用构建机器上的稳定本地开发代码签名证书，不是 Apple 颁发的开发者证书，未经过 Apple 公证。
