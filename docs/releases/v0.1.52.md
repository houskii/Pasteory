# Pasteory 0.1.52 Beta

- 图片格式、尺寸和文件大小单独一行展示，OCR 图标移到识别正文左侧。
- 统一各类卡片底部时间、复制次数和粘贴次数的左边线与底边距。
- 图片、文件和混合内容的纯文本复制／粘贴优先使用当前备注，展开 `[OCR:…]`，保留原备注、识别文字、换行和普通方括号。普通文字仍使用完整原文。
- 兼容旧版已识别、尚未写入备注的图片文字；用户修改或删除 OCR 后按当前内容处理。
- 纯文本准备失败时保留原剪贴板内容。普通图片和文件复制继续写入原始格式。

适用于 Apple Silicon，macOS 14 及以上。继续使用现有 Sparkle 更新密钥及应用代码签名身份。

安装包使用本机生成的 Pasteory Local Build 证书签名，该证书不是 Apple 颁发的开发者证书。安装包未经过 Apple 公证。
