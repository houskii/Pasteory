# Pasteory Beta 0.1.43 (48)

- 图片 OCR 设置移到“采集与隐私”，与剪贴板检测放在一起。开关、识别方式和仅处理新增图片的规则保持原样。
- 资料库直接显示在侧栏顶部，取消重复的“内容”标题。设置分类调整为“应用设置”“采集与处理”“数据与支持”。
- 文字现在默认使用内置预览，无需配置外部应用。支持 Markdown 与原文切换、标题、列表、任务列表、表格、引用和代码块；资料库详情可展开为独立预览窗口。
- 预览读取原始文本，按需在后台解析并缓存，列表不逐条渲染。长文本限制预览长度，复制原文保留完整内容。未配置代码编辑器时也能使用内置文字预览。
- 接入 MIT 开源组件 MarkdownUI 2.4.1，保留 macOS 14 支持；新依赖的许可随应用一同分发。

安装包为 Apple Silicon Release 构建，使用本机生成的 Pasteory Local Build 证书签名，未经过 Apple 公证。应用更新仍需用户确认后才下载安装。

本版本通过 GitHub Release 提供手动安装包和 SHA-256 校验文件。由于本机构建环境缺少已发布版本的 Sparkle 更新私钥，本次不更新应用内自动更新索引；继续保留客户端已信任的更新公钥。
