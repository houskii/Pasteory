# 快捷面板交互

快捷面板打开后，默认选中列表中的第一项，但不把输入焦点放进搜索框。这样空格可以直接执行“打开所选内容”，不会意外输入到搜索框。

## 打开和搜索

- 空格默认打开当前选中的内容，可以在“设置 → 快捷键 → 内容打开”中修改或关闭。
- `⌘F` 默认进入搜索，再按一次退出搜索输入，可以在“设置 → 快捷键 → 搜索”中修改或关闭。
- 搜索框有焦点时，普通字符和空格都用于输入，不触发列表操作。`⌘F` 仍然可以退出搜索。
- 方向键只在搜索框没有焦点时用于选择项目和切换分组。

## 不同内容如何打开

| 内容 | 打开方式 | 未配置时 |
| --- | --- | --- |
| 网页 | 使用“设置 → 打开方式”中指定的浏览器 | 不打开，并提示先选择浏览器 |
| 图片 | 使用 macOS 自带的“预览” | 如果原始图片已经不可用，则提示无法打开 |
| 代码 | 按识别出的语言生成临时文件，再使用指定的代码编辑器 | 不打开，并提示先选择编辑器 |
| 文件 | 按文件后缀查找自定义应用，例如 `pdf → 预览` | 没有后缀或没有匹配规则时不打开 |
| 文字、颜色、混合内容 | 当前版本不支持 | 明确提示不支持，不调用系统默认应用猜测 |

代码和剪贴板图片生成的临时文件位于系统临时目录。Pasteory 不会把它们写进资料库，也不会改动原始文件。文件类型打开的是原始文件引用。

## 列表性能

快捷面板和资料库共用缩略图内存缓存。相同内容再次出现在可见区域时，不重复读取和解码附件；内容哈希变化后会使用新的缓存项。鼠标经过哪一行只用于确定右键菜单目标，不再触发整列卡片刷新。
