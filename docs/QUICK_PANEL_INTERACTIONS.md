# 快捷面板交互

快捷面板打开后，默认选中列表中的第一项，但不把输入焦点放进搜索框。这样空格可以直接执行“打开所选内容”，不会意外输入到搜索框。

## 打开和搜索

- 从其他 App 用全局快捷键唤起后，Pasteory 会在面板仍隐藏时先完成定位和应用激活，再一次性显示并取得键盘焦点。不能先显示一个无焦点窗口、下一轮 RunLoop 再激活重排；按 `Esc` 关闭时恢复唤起前的 App。
- 空格默认打开当前选中的内容，可以在“设置 → 快捷键 → 内容打开”中修改或关闭。
- `⌘F` 默认进入搜索，再按一次退出搜索输入，可以在“设置 → 快捷键 → 搜索”中修改或关闭。
- 鼠标点击搜索框的文字区、搜索图标或框内空白区域时，搜索框立即获得输入焦点，不要求先按 `⌘F`。
- 关闭快捷面板时会同时清空搜索词，下次打开后从完整列表开始。
- 搜索框有焦点时，上下方向键仍可切换所选项目，左右方向键不移动光标，也不切换分组。
- 搜索框有焦点时，所有包含 Command 的已配置快捷键及 `⌘1～⌘9` 仍然生效。搜索是实时的，不需要按 Return 提交；没有输入法候选时，Return 执行它当前绑定的快捷操作，默认粘贴所选内容。输入法正在组合中文时，第一次 Return 只用于确认候选词。空格和其他普通字符继续输入搜索词。
- 搜索框没有焦点时，上下方向键选择项目，左右方向键循环切换分组。在“全部”按左键进入最后一个分组，在最后一个分组按右键回到“全部”。
- 底部只保留方向键提示和“长按 Command 提示”。空格打开、`⌘F` 搜索及其他快捷键统一放进快捷操作浮窗。
- 单独按住 Command 满 1 秒后显示快捷操作帮助。Command 与 Shift 或其他按键组合使用时不会显示，松开 Command 后立即隐藏。
- 快捷操作浮窗与快捷面板顶部对齐，优先显示在右侧；右侧空间不足时显示在左侧。浮窗按设置页的分组和文案逐行显示快捷键，每行一项。内容不超过快捷面板高度时不滚动，超过后才限制高度并允许纵向滚动。
- 顶部分组标签使用图标区分类型：普通分组显示文件夹，智能分组显示星光，与资料库左侧的分组样式一致。
- 顶部分组标签使用 `12 pt` 文字、较小的水平留白，名称最多占 `68 pt`；超长名称在标签内截断，悬停后显示完整名称。标签区支持横向滚动，切换分组时自动把当前标签滚到中间，避免长名称让快捷面板只能露出两三个分组。
- 标签区下面显示不可点击的当前位置：左侧为完整的当前分组名称，右侧为“第 x / y 个分组”。选中“全部”时改为“共 y 个分组”。这行只说明位置，不响应方向键，也不使用 Tab 的选中样式。
- 底部的“今日”按本机当前时区从当天 `00:00` 开始统计；“近 7 日”从六天前的 `00:00` 开始并包含今天。两项都按最近复制时间计算，不包含废纸篓。

## 分组顺序和全部分组

- “全部”固定在第一项，不参与拖曳。普通分组和智能分组都可以直接在顶部标签条里拖动，拖曳后立即更新顺序，再把统一的 `sortOrder` 保存到数据库。
- 普通分组和智能分组可以在快捷面板中交叉排序。资料库仍按类型分区，只读取各类型在统一顺序中的相对位置；在资料库内拖动某一类型时，不能打乱另一类型已经排好的位置。
- 标签条最右侧固定显示“全部分组”图标和分组总数。原来的 `+` 菜单移除，新建和管理操作统一放进“全部分组”。
- “全部分组”使用纵向列表显示完整名称、类型图标、当前选中项和拖动手柄。可以拖到另一项前面，也可以拖到列表末尾的放置区。
- 主面板继续使用左右键切换标签、上下键选择内容。打开“全部分组”后，上下键在分组列表中移动，Return 进入分组，Esc 关闭总览；关闭后恢复主面板原来的方向键含义。
- “全部分组”容器需要保留键盘焦点来接收这些按键，但不显示 macOS 默认的蓝色焦点描边；当前分组继续用主题色背景和勾选表示。
- “新建分组”和“新建智能分组”复用资料库的编辑器，不再使用 `NSAlert` 输入名称。普通分组创建页负责名称；普通分组的成员继续通过内容 item 的“设置分组”管理。智能分组创建页支持嵌套规则组，每一组都可以独立选择“满足全部”或“满足任一”；匹配预览同时展示标题和原始内容，并可滚动查看全部结果。
- “新建分组”默认使用 `⌘⇧N`，可以在设置页修改或关闭。快捷键从主面板直接打开普通分组编辑器，不要求先展开“全部分组”；“全部分组”中的新建入口和长按 Command 的快捷操作提示都会显示当前配置。
- 分组右键菜单继续支持重命名、编辑智能规则和删除。编辑器或删除确认正在显示时，快捷面板暂停自己的 Return 和方向键监听，按键只交给当前编辑界面。
- 无修饰的左、右方向键先作为分组导航处理，再判断可配置快捷动作。普通内容的“设置分组”不再使用可被右方向键展开的二级菜单，避免菜单跟踪状态把左右导航误解为打开分组。

## 编辑信息和设置分组

- 普通内容不再使用单独的“设置分组”弹窗。标题、备注和普通分组统一放在“编辑信息”弹窗中，一次保存。
- “编辑信息”使用快捷面板内部的模态层，不再把 SwiftUI sheet 挂到非激活的 `NSPanel` 上。编辑层始终限制在面板边界内，标题和底部操作固定，中间表单统一滚动；面板靠近屏幕边缘时也不能裁切、错位或互相覆盖。
- `⌘E` 打开同一弹窗并从标题开始；`⌘G` 打开后直接聚焦分组列表。右键菜单中的“编辑信息…”和“设置分组…”也分别进入对应位置。
- 编辑弹窗由整个快捷面板统一管理，并记录正在编辑的内容 ID，不再由每张内容卡片各自保存开关状态。`Esc`、取消、保存、关闭快捷面板或切换顶部分组都会清空这个 ID，旧卡片状态不能在另一个分组中再次触发弹窗。
- `Tab` 按“标题 → 备注 → 分组”向前切换，`Shift-Tab` 反向切换。没有普通分组时自动跳过分组区。
- 分组区用 `↑ / ↓` 移动当前项，用 `Space` 勾选或取消。高亮项和已勾选项必须有不同的视觉状态，焦点容器不显示系统蓝色描边。
- `Return` 保存标题、备注和分组，`Esc` 取消全部未保存修改。切换勾选时只更新弹窗草稿，不能在用户取消后留下部分分组修改。
- 聚合父项仍使用自己的“设置聚合分组”界面；普通内容和聚合成员使用统一的编辑信息弹窗。

## 不同内容如何打开

| 内容 | 打开方式 | 未配置时 |
| --- | --- | --- |
| 链接 | 使用“设置 → 打开方式”中指定的浏览器 | 不打开，并提示先选择浏览器 |
| 图片 | 使用 macOS 自带的“预览” | 如果原始图片已经不可用，则提示无法打开 |
| 代码 | 按识别出的语言生成临时文件，再使用指定的代码编辑器 | 不打开，并提示先选择编辑器 |
| 文件 | 按文件类型使用指定 App，或通过 bash／zsh 执行包含 `$file` 的自定义命令 | 没有匹配规则、配置不完整或原文件已删除时不执行 |
| 文字、颜色、混合内容 | 当前版本不支持 | 明确提示不支持，不调用系统默认应用猜测 |

代码和剪贴板图片生成的临时文件位于系统临时目录。Pasteory 不会把它们写进资料库，也不会改动原始文件。文件类型打开的是原始文件引用。

同时复制多个文件时只生成一条内容卡片，不再用第一个文件冒充整条内容。卡片显示堆叠的文件类型图标、“x 个文件”和前三个文件名；详情页逐项显示全部文件的图标、名称、大小及是否已删除。复制和粘贴继续保留全部文件及原顺序；执行打开时先检查每个文件是否存在且都有可用规则，全部检查通过后再逐项使用各自的 App 或命令处理，避免只处理第一个文件或处理中途才发现后续文件没有配置。

文件命令可以静默执行，也可以显示在新建的 Terminal.app 窗口中。显示窗口时，Pasteory 先把工作目录、`$file`、PATH 和用户命令写入权限为当前用户可读的一次性脚本，终端只显示简短的脚本启动命令和实际输出，不展开整段内部参数。命令结束后保留结果 3 秒，再关闭本次新建的窗口；已有终端窗口不受影响。脚本执行后自动删除。Shell 统一选择 bash 或 zsh，原文件绝对路径通过 `$file` 环境变量传入，工作目录为文件所在目录。

静默执行时，规则旁显示最近一次任务状态，并提供实时刷新的“文件静默命令日志”。这里只记录该 bash／zsh 文件命令的 stdout 和 stderr，不包含 Pasteory App 日志。任务失败时显示退出码；单次日志限制为 1 MB，只保留最近 20 份。用户也可以从设置页直接在 Finder 中打开静默命令日志目录。终端窗口模式的输出只显示在终端里，不写入这个目录。

静默任务不接受标准输入。命令如果需要密码、确认或其他交互，应该切换到终端窗口模式；否则 stdin 会直接返回 EOF，并在日志中留下命令自己的错误输出。

## 聚合内容

“聚合内容”的默认快捷键为 `⌘B`，可以在“设置 → 快捷键 → 整理当前项目”中修改或关闭。它与现有的 `⌘F` 搜索、`⌘G` 设置分组以及 Return 粘贴不冲突。长按 Command 的快捷操作帮助需要显示这一项。

聚合父项默认使用 `⌘↓` 展开并恢复上次选中的子项，使用 `⌘↑` 从子项返回父项并收起。两个快捷键都可以在设置页修改或关闭。

版本升级时保留用户已经保存的聚合快捷键，不用新的发布默认值覆盖。

快捷键根据当前状态确定作用范围：

| 当前状态 | `⌘B` 的行为 |
| --- | --- |
| 搜索词不为空，没有进入多选 | 聚合当前搜索结果 |
| 已经选择两个或更多内容 | 聚合所选内容 |
| 普通列表中只有当前项 | 进入多选，并勾选当前项 |
| 选中聚合父 item | 打开聚合成员编辑 |
| 可用内容少于两项 | 不创建，提示至少需要两项不同内容 |

搜索框有焦点时，`⌘B` 仍然生效。搜索结果区在结果数量右侧增加“聚合结果”按钮，并把按钮靠右放置；按钮和快捷键执行同一个动作。

### 聚合当前搜索结果

用户输入搜索词后，Pasteory 先完成搜索，再允许创建聚合：

1. 当前查询和筛选命中的普通内容进入候选范围。
2. 相同内容已经在保存层合并，不会重复计数。
3. 如果搜索结果包含已有聚合，确认页会把它展开成成员内容并去重，不创建聚合套聚合。
4. 点击“聚合结果”或按 `⌘B` 后打开确认层，不立即保存。
5. 确认层显示最终内容数量，标题默认使用“搜索词 + 相关内容”，允许修改标题和备注。
6. 创建成功后退出搜索，选中新聚合并保持收起，同时显示“已聚合 x 项内容”和“撤销”入口。

“当前搜索结果”指当前资料范围、筛选条件和搜索词命中的全部内容，不是屏幕上已经渲染出来的几行。确认层必须显示完整命中数；如果实现层限制了最大数量，还要明确显示未包含多少项，不能静默截断。

确认层中的 `Return` 执行创建，`Esc` 返回搜索结果。取消确认不能关闭整个快捷面板，也不能清空搜索词。搜索结果只有一项时，“聚合结果”按钮禁用，并说明至少需要两项不同内容。

`Esc` 按当前最上层状态逐层返回：先关闭聚合确认层，再退出多选；只有没有确认层和多选状态时才关闭快捷面板。这样取消一次聚合不会连带退出整个面板。

搜索结果聚合默认保存创建当时的固定成员。需要随搜索条件持续变化时，继续使用智能分组；创建确认层不增加容易混淆的“动态聚合”开关。

搜索结果聚合的默认标题是“搜索词 + 相关内容”，例如 `abmock 相关内容`；手动多选的默认标题是“新建聚合”。备注默认留空，卡片不显示空备注占位。标题为空时不能创建；旧数据若没有标题，则显示“未命名聚合”。

聚合父项右键菜单中，凡是已经在设置页配置快捷键的操作，都必须在菜单右侧显示当前快捷键，包括展开或收起、编辑信息、收藏、置顶、设置分组和删除聚合。批量整理成员目前没有独立快捷键，因此不显示虚假的快捷键提示。

### 普通列表多选

- `Command` 点击切换单项选择，`Shift` 点击选择连续范围。
- 进入多选后，方向键移动当前项，`Space` 勾选或取消，`Return` 打开聚合确认层。
- 多选工具条显示“已选 x 项”，右侧提供“聚合”按钮。
- `Esc` 退出多选并恢复进入前的单项选择。
- 聚合子 item 参与多选时使用它引用的原内容 ID；同一内容即使从多个聚合位置选中，也只计一次。

聚合确认层只保存成员引用，不移动或复制原内容。创建后，聚合父 item 不直接打开、复制或粘贴；用户需要先展开并选择具体子 item。

## 列表性能

快捷面板和资料库共用缩略图内存缓存。相同内容再次出现在可见区域时，不重复读取和解码附件；内容哈希变化后会使用新的缓存项。鼠标经过哪一行只用于确定右键菜单目标，不再触发整列卡片刷新。
