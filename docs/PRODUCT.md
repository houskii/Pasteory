# Pasteory 产品文档

## 产品核心洞察（Insight）

**Pasteory learns from what you copied.**

从复制过的内容里，学会你做事的习惯。

复制行为会留下用户的工作线索：用户在什么场景下找内容，哪些内容会被反复使用，又有哪些操作总是接连发生。记录积累得足够多之后，这些线索会显出稳定的习惯。

Pasteory 保存并整理过去的复制记录，产品目标是从中识别重复出现的内容和使用方式。在下一次需要时，它要让用户更快找到内容、继续操作，逐渐减少重复劳动。

这条洞察决定了产品的基本方向：历史记录要可靠，整理方式要贴合用户原本的习惯，所有帮助都要落实到下一次使用是否更省事。

## 产品定义

Pasteory 是一个本地优先的 macOS 剪贴板资料库。它在菜单栏运行，保存文字、图片、链接、颜色、代码和文件引用，并通过快捷面板帮助用户搜索和再次使用过去复制的内容。

## 当前产品边界

v0.1.9 以可靠记录、快速找回和本地隐私为主：

- 所有内容保存在当前 Mac，不上传网络。
- 默认忽略密码、钥匙串和隐藏剪贴板内容。
- 文件只保存引用和元数据，不复制原始文件。
- 网页标题解析默认关闭。用户主动打开后，Pasteory 会先匿名访问新复制的 HTTP／HTTPS 链接；受保护站点通过内置范围或用户添加的正则进入登录解析，正则直接匹配不含协议的 `host + path`。完成登录后，当前覆盖的失败链接会批量重试，以后新复制的匹配链接自动复用同一 WebKit 会话。无法取得真实标题时，仍保留本地 URL 兜底标题和失败原因。
- 当前版本不包含 AI 分析或云同步。

后续功能是否值得做，要回到产品核心洞察判断：它有没有从过去的复制行为中学到有用的习惯，并让下一次操作更省事。
