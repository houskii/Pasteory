# Pasteory v0.1 验收记录

## 自动化验证

- `make test`：分类、颜色识别、多项内容、跨时间和来源的全局去重、旧重复数据迁移、聚合持久化、中文搜索、智能规则、普通分组归档豁免、LZFSE 恢复、备份往返测试全部通过。
- `make benchmark`：使用完整 Clip JSON、SQLite 和 FTS5 路径生成 10,000 与 100,000 条样本，每组执行 20 次搜索。
  - 10,000 条：搜索 `p95 8.49 ms`。
  - 100,000 条：搜索 `p95 9.02 ms`。
- `make verify`：检查 Bundle ID、版本、最低系统版本、arm64 架构、稳定证书签名、Designated Requirement 和 DMG 校验和；检测到 ad-hoc 签名时必须失败。

## 运行态验证

- 应用安装在 `/Applications/Pasteory.app`，进程类型为 `UIElement`，不显示 Dock 图标。
- 默认全局快捷键为 `⌘⇧V`，支持在设置中录制其他组合；新安装和“恢复全部默认快捷键”都使用当前发布基线，升级时不覆盖用户已经保存的配置。
- 默认自动记录新复制内容；菜单栏不展示“监控中”“暂停监控”等容易误解的状态。
- 菜单栏使用标准方形槽位和 macOS Template Image：浅色菜单栏显示深色图形，深色菜单栏显示浅色图形，点击高亮时由系统自动反色。单色轮廓必须从应用图标准稿提取，P 的字腔位置、大小和弧线必须与准稿一致，夹扣只在最前层出现；`18 × 18` 与 `36 × 36` 资源的可见边界比例必须一致，Retina 下不能缩成一枚很小的 P。
- 快捷面板使用无标题栏瞬时样式，没有红黄绿窗口按钮，失去焦点后收起。
- 快捷面板打开后默认不聚焦搜索框；空格打开所选内容，`⌘F` 进入或退出搜索。关闭面板时清空搜索词。搜索框有焦点时，上下方向键选择项目、左右方向键禁用，包含 Command 的快捷键继续生效，空格等单键只用于输入。
- 搜索框没有焦点时，左右键循环切换顶部分组：“全部”向左进入最后一个分组，最后一个分组向右回到“全部”。无修饰左右键不能触发“设置分组”快捷动作或弹窗。
- 从其他 App 用全局快捷键唤起面板后，不需要再点击面板即可使用上下左右、空格、Return、Esc 和已配置快捷键；面板首次出现的位置必须与最终位置一致，不能先闪现在错误位置再跳动；如果 Pasteory 为获取键盘焦点临时成为活动应用，按 `Esc` 后应回到唤起前的 App。
- 搜索结果实时更新，不使用 Return 提交搜索。搜索框有焦点且输入法没有待确认文本时，Return 执行当前绑定的快捷操作，默认粘贴所选内容；输入法正在组合文本时，Return 先确认候选词，不得误触粘贴。
- 鼠标点击搜索框的文字区、搜索图标或框内空白区域都能直接获得输入焦点；默认焦点逻辑不能在点击后立即撤回光标。
- `⌘B` 默认执行“聚合内容”：搜索中聚合当前结果，多选时聚合所选内容，普通单选时进入多选。搜索结果区提供同名按钮；确认前显示去重后的内容数量，少于两项时不得创建。
- 聚合父项不直接打开、复制或粘贴；`⌘↓` 展开并恢复上次选中的子项，`⌘↑` 返回父项并收起。父项的收藏、置顶和分组只作用于聚合自身，批量操作必须明确写成“全部成员”。
- 聚合父项右键菜单对展开或收起、编辑、收藏、置顶、设置分组和删除显示用户当前配置的快捷键；没有独立快捷键的批量操作不显示提示。
- 快捷操作帮助只在单独长按 Command 满 1 秒后显示，组合键和短按不会触发；浮窗优先显示在快捷面板右侧，右侧空间不足时切到左侧，顶部与快捷面板对齐。
- 底部提示只保留方向键和“长按 Command 提示”；空格、`⌘F` 及其他快捷键按设置页分组逐行显示在浮窗中，内容超过快捷面板高度后才允许滚动。
- 底部统计使用本机时区的自然日：“今日”从当天 `00:00` 开始，“近 7 日”从六天前的 `00:00` 开始并包含今天，不再使用向前滚动 24 小时或 168 小时的口径。
- 顶部分组标签使用紧凑字号和留白，长名称最多占 `68 pt` 并在悬停时显示全名；标签区可以横向滚动，当前分组会自动滚动到可见区域。
- 顶部分组标签支持直接拖曳排序，普通分组和智能分组共用一个持久化顺序，“全部”固定不动。标签下方显示“当前：分组名”和“第 x / y 个分组”；选中全部时显示分组总数，这一行不响应方向键。
- 标签条右侧的“全部分组”入口显示分组数量，展开后可以查看完整名称、选择、拖动、编辑和删除分组。原来的 `+` 弹窗已移除；新建普通分组和智能分组复用资料库编辑器，智能分组创建时可以配置规则并预览匹配内容。
- 快捷面板默认使用 `⌘⇧N` 直接新建普通分组；该快捷键可以在设置页修改或关闭，并显示在长按 Command 的快捷操作提示中。升级时不能覆盖用户已经占用 `⌘⇧N` 的配置。
- 普通内容的“编辑信息”和“设置分组”打开同一个弹窗：`⌘E` 聚焦标题，`⌘G` 聚焦分组；`Tab / Shift-Tab` 在标题、备注和分组之间切换，分组区使用 `↑ / ↓` 和 `Space`，`Return` 一次保存，`Esc` 取消且不留下部分修改。
- “编辑信息”必须完整显示在快捷面板内部，标题栏和底部按钮固定，中间表单可以滚动；无论快捷面板位于屏幕顶部、底部还是边缘，都不能出现字段裁切、内容重叠或按钮漂移。
- 在一个分组中打开编辑信息并按 `Esc` 后，再切换到另一个分组，编辑弹窗不能重新出现。
- 设置页使用与资料库一致的左侧导航，按“基础设置”“交互与内容”“数据与支持”分组。
- “存储与清理”默认显示近 7 个自然日的保存条数，并支持切换 1 天、7 天、30 天和总共；统计包含已归档内容、排除废纸篓，时间以最近复制时间为准。
- 内容趋势统一使用横向堆叠条：1 天和总共各显示一行，7 天显示最近 7 行，30 天保存 30 行但可视区域固定为 7 行并支持纵向滚动。每行横条长度体现当天总量，条内颜色体现当天的类型构成，右侧直接显示条数；图例按所选范围汇总类型、条数和比例。磁盘占用独立展示数据库、图片与附件、归档、备份、日志和其他资源，并显示 Pasteory 总占用及其占本机磁盘的比例。
- 存储大小按文件实际分配空间计算；SQLite 的 WAL、SHM 计入数据库，直接复制并保存的图片计入图片与附件，外部文件引用的原文件大小不计入 Pasteory 占用。
- 主题色可以在设置中切换；侧边栏、主要按钮、快捷面板标签、资料库选中态、置顶态、内容类型标签和品牌渐变会立即更新。
- 链接、代码和文件只有在“打开方式”中配置完成后才能打开；图片固定使用系统“预览”。
- 列表按复制时间倒序，时间显示为 `MM-DD HH:mm`；左侧显示来源应用图标，图片显示缩略图。
- 图片缩略图旁分三行显示图片信息：`图片格式: png`、`图片大小: 123 * 1234`、`文件大小: 78.0 KB`。尺寸取图片的实际像素宽高，文件大小沿用一位小数的十进制单位；快捷面板和资料库都必须完整显示三行，图片加载失败后显示图片回退图标，不持续转圈。
- 直接复制的图片二进制会保存到 Pasteory 的 `Attachments`，来源页面关闭或来源应用中的原图删除后仍然可用，并随备份一起导出。Finder 中复制的图片文件仍按文件引用处理；除非剪贴板同时包含完整图片数据，否则原文件删除后无法恢复原图。
- 文件根据完整文件名、复合后缀和普通后缀选择默认图标，同时显示文件名、可解析的父目录路径和实际文件大小；路径中不重复文件名。文件附带的 ICNS、TIFF 或 PNG 图标不能触发内容缩略图。
- 原文件不存在时，快捷面板、资料库列表和详情将文件标为“已删除”，文件名加删除线，整项置灰；重新打开快捷面板、切换分组或从访达回到 Pasteory 时必须重新检查，不能沿用卡片首次显示时的状态。此时拒绝打开 App 或执行命令。
- 文件打开规则沿用文件图标系统的预设后缀，并允许新增 `.hap`、`.tar.gz` 等自定义后缀。目录按后缀升序排列，先显示后缀，再显示文件图标和类型说明；每条规则只匹配一个后缀，自定义规则优先于同后缀的预设规则。每条规则可以选择 App，或者使用统一配置的 bash／zsh 执行自定义命令。原文件绝对路径通过 `$file` 环境变量传入。
- 命令默认显示在新建的 Terminal.app 窗口中，终端只回显简短的一次性脚本路径和实际输出，不展开工作目录、`$file`、PATH 或用户命令。完成后保留 3 秒再关闭该窗口，一次性脚本随即清理；也可以改为静默执行。静默执行不加载 shell 登录配置，显示窗口首次使用需要 macOS 自动化权限。
- 文件规则使用静默执行时，会把该 bash／zsh 命令的 stdout 和 stderr 合并写入独立日志，并在对应规则旁显示“执行中”“已完成”或退出码。日志不包含 Pasteory App 的运行信息，终端窗口模式也不写入这里。日志查看器每 0.5 秒刷新，可以在任务运行时观察输出；单次最多保存 1 MB，目录最多保留最近 20 份，失败时在 Pasteory 内提示查看本次命令输出。
- 静默命令的 stdin 连接到空设备，不显示输入框。需要密码、确认或其他标准输入的命令必须使用终端窗口模式。
- 文件大小使用 `B`、`KB`、`MB`、`GB` 十进制单位并固定保留一位小数。
- 颜色内容在列表和详情中显示真实色块，旁边保留原始颜色值；十六进制、RGB、RGBA、HSL 和 HSLA 均可渲染。
- 列表滚动时，鼠标经过状态不会触发整列刷新，已加载的图片缩略图不会重复读取和解码。
- 资料库详情展示最近复制来源；链接内容同时展示已经保存的解析标题、状态、来源和尝试时间。
- 从快捷面板或资料库执行粘贴后，原内容不改变排序位置，复制次数不增加，粘贴次数增加 1；仅复制或粘贴失败时不增加粘贴次数。
- 完全相同的内容跨来源 App、跨时间和归档状态复用同一个普通 item；保留首次创建时间，更新最近复制时间并逐次保存抓取来源。启动时会把旧重复记录合并，原记录 JSON 留在 `clip_merge_backups` 中以便恢复。
- 聚合父项在快捷面板和资料库内联展开完整子卡片；子项可以只移出当前聚合，删除聚合不会删除原内容。搜索命中成员时保留父子关系，并显示 `匹配 x / y`。
- 资料库使用 Pasteory 自定义三栏布局：左侧为蓝紫选中态导航，中间为圆角内容卡片，右侧为预览与编辑卡片；窗口宽度小于 1050 pt 时隐藏详情栏。
- 资料库实际运行截图见 [`actual-library-redesign.png`](actual-library-redesign.png)，设计与实现说明见 [`LIBRARY_UI.md`](LIBRARY_UI.md)。
- 没有辅助功能权限时，Return 会先复制内容并触发系统授权提示。授权后的真实目标输入框粘贴需要用户手动完成系统权限授权后复验。

## 交付边界

- 网页标题解析默认关闭；用户主动打开后，只对新复制且符合安全策略的 HTTP／HTTPS 链接发起匿名请求。BITS、飞书、Codebase 和用户添加的登录解析规则只有在用户主动建立 Pasteory 独立 WebKit 会话后才使用 Cookie；会话不读取 Chrome Cookie，并按 Bundle ID 隔离。
- BITS MR、BITS 构建日志、ByteCloud TOS Bucket、飞书 Wiki、知乎回答和微信公众号链接支持本地兜底标题。
- “链接解析 → 已解析”按具体 URL 展示最后一次成功标题、解析来源和次数；资源级重新解析失败时保留成功标题，并标记最近失败状态。
- `Bits` 和通用 ByteCloud 站点壳标题不能覆盖兜底标题；失败结果按 URL 路由聚合并保留原因。
- 用户可以从未解析路由创建兜底规则，保存后回填现有链接和搜索索引。
- “添加登录解析”只配置需要登录的网站，不再提供“仅保存”和“匿名解析”按钮。匹配规则使用正则表达式，作用于不含协议的 `host + path`，可以直接输入 `code\.byted\.org/.*`。
- 保存登录解析规则时显示当前覆盖的路由和链接数量；完成登录后批量重试现有命中链接，以后新复制的命中链接自动使用同一 WebKit 会话。Codebase 合并请求属于内置登录解析范围。
- 未解析路由按 host 与路径模板聚合，可选 query 参数不会拆成不同分组；自动生成的规则只把标题模板实际引用的 query 变量设为必需条件。
- 当前版本没有 AI 分析、云同步或 OCR。
- 文件内容只保存引用，不复制文件实体。
- 同时复制多个文件时只生成一张汇总卡片，显示文件总数、堆叠类型图标和文件名摘要；详情逐项显示全部文件及缺失状态。复制、粘贴和打开都处理完整文件列表，不能静默只使用第一项。
- 正式包包含 49 个 `128 × 128` PNG 文件图标，构建时必须校验数量完整。
- 本地安装包使用隔离钥匙串中的 `Pasteory Local Build` 稳定签名，没有经过 Apple 公证。
- 首次执行 `make app` 会自动初始化本地身份并锁定证书指纹；后续构建、打包、安装和验证都必须拒绝 ad-hoc 签名。
- `make qa-verify` 必须确认正式包为 `app.pasteory.Pasteory`、QA 包为 `app.pasteory.Pasteory.qa`，两者的数据目录、原生消息桥名称和 designated requirement 均不相同。
- 从 ad-hoc 版本切换后需要重新授予一次辅助功能权限；之后连续更新安装不应再次丢失授权。
