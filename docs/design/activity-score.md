# 活跃度算法

状态：0.1.54 已实现。默认参数为半衰期 48 小时、再次复制 +0.4、成功粘贴 +0.8。

## 旧版新内容为什么显示 68%

0.1.53 及更早版本的标准策略见 `Sources/PasteoryAI/Lifecycle.swift`：最近使用占 60%，使用频率占 25%，不同日期的持续使用占 15%。

新采集的内容记录了一次复制。此时最近使用值为 1，频率值为 `ln(2) / ln(21)`，持续使用值为 `1 / 7`。

```text
100 × (0.60 + 0.25 × ln(2) / ln(21) + 0.15 / 7)
= 67.8346%
```

因此新内容显示约 68%。这个初始值不符合“刚复制的内容最需要使用”的预期。

资料库的“活跃度”显示分值，“活跃度前 N%”显示全库排名。同分内容并列，排名百分比包含全部同分内容。

## 默认参数

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| 新内容分值 | 100% | 首次采集时直接设为满分 |
| 普通内容半衰期 | 48 小时 | 没有再次使用时，48 小时降到 50% |
| 再次复制的系数增量 x | 0.4 | 复制一次增加 0.4，延缓后续衰减 |
| 成功粘贴的系数增量 y | 0.8 | 粘贴比单纯复制体现更明确的使用意图 |
| 最大系数 | 4 | 控制反复使用带来的累计加成 |
| 加成的半衰期 | 7 天 | 加成也随时间衰减，逐渐回到普通内容的水平 |

首次采集的复制不再额外计入复用加成。之后每次真实复制、成功粘贴，分值恢复到 100%，重新计时，同时增加对应系数。Pasteory 粘贴时内部写入剪贴板只计这一次粘贴事件。

## 计算公式

保存真实使用事件及最近一次使用时间 `lastUsedAt`，按事件时间顺序计算复用加成 `b`。新内容的 `b = 0`，最大值为 3；加成从对应复制、粘贴事件的时间独立衰减。

设 `d` 为距最近一次使用的天数，`e` 为距最近一次复制或粘贴的天数，最小均取 0；`b` 为该复制或粘贴发生后的加成。只有复制、粘贴时，`d` 与 `e` 相同；手动打开或编辑只重置 `d`。

```text
当前加成 = b × 2^(-e / 7)
当前系数 k = 1 + 当前加成
活跃度 A = clamp(100 × 2^(-d / (2 × k)), 0, 100)
```

每次使用先衰减原有加成，再累加本次增量：

```text
复制后：b = min(3, 当前加成 + 0.4)
粘贴后：b = min(3, 当前加成 + 0.8)
lastUsedAt = 本次使用时间
```

每次使用后的 `d = 0`，所以分值为 100%。系数增量用于延长后续保温时间；分值不会超过 100%。停止使用后，分值和加成都会逐渐降低。

## 衰减计算

下表从最近一次使用开始计算，之后没有再操作。“再次复制”和“成功粘贴”两列分别假设原加成为 0，本次只增加一次对应事件。

| 距最近一次使用 | 普通内容 | 再次复制一次 | 成功粘贴一次 |
| --- | ---: | ---: | ---: |
| 刚使用 | 100.00% | 100.00% | 100.00% |
| 6 小时 | 91.70% | 93.96% | 95.25% |
| 12 小时 | 84.09% | 88.20% | 90.63% |
| 24 小时 | 70.71% | 77.54% | 81.79% |
| 48 小时 | 50.00% | 59.34% | 65.80% |
| 72 小时 | 35.36% | 44.86% | 52.09% |
| 7 天 | 8.84% | 13.24% | 17.68% |
| 14 天 | 0.78% | 1.21% | 1.75% |
| 30 天 | 0.0031% | 0.0038% | 0.0046% |

例如，普通内容在第 2 天降到 50%。这时再复制一次，活跃度恢复到 100%，系数变为 1.4；如果是成功粘贴，系数变为 1.8。原有加成先按时间衰减，再累加本次增量。

## 计算与现有数据

- 使用事件发生时仅更新本条使用记录。显示、排序时按当前时间计算，不需要定期更新全库数据库。
- 分组继续汇总成员分值，复用现有 Top K 均值和全部成员均值的加权方式。内容分值与分组分值都限定在 0～100%。
- 旧内容从已保存的真实使用事件重放加成，最多使用现有 366 天、4096 条的事件记录。首次采集时间用于排除初次复制；旧资料只保留最后复制、粘贴时间时，仅采用这些确知的事件，不用终身复制次数推造历史。
- OCR、AI 整理、链接解析、列表浏览不更新使用时间，也不增加系数。
- 本方案定义活跃度分值。留存、压缩与归档继续使用现有时间节点和收藏、置顶保护规则。

在“AI 整理 → 生命周期与压缩 → 活跃度计算”中调整半衰期、复制增量和粘贴增量；加成上限与衰减周期固定采用上表默认值。手动打开或编辑刷新最近使用时间，不增加复制、粘贴加成，也不会重置原有加成的衰减时间。

成功粘贴先回写系统剪贴板，再发送粘贴快捷键。回写会被 `ClipboardMonitor.markOwnWrite` 排除，调用方只记录 `.paste`；若自动粘贴失败并退回复制，则只记录 `.copy`。当前成功判断是已向前台目标应用发出粘贴快捷键，未读取目标应用确认插入结果；在目标应用里另外手动按 Command+V 的行为无法由剪贴板监视器统计。
