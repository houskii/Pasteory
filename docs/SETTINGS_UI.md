# 设置页设计与实现

Pasteory 的设置页使用左侧导航和右侧内容区。资料库直接嵌入右侧，其他设置仍使用标题和分组表单；资料库不重复显示品牌标题和设置入口。

窗口默认内容尺寸为 `1360 × 820`，支持缩放和尺寸记忆；常规最小尺寸为 `1120 × 720`，小屏幕按可用区域缩小。资料库三栏的显示阈值按右侧实际可用宽度计算。`⌘L` 和菜单栏“打开资料库”定位同一个设置窗口中的资料库；`⌘,` 定位通用页。切换页面保留资料库的查询、筛选和选中项。

## 页面分组

- 内容：资料库。
- 基础设置：通用、采集与隐私。
- 交互与内容：快捷键、打开方式、链接解析。
- 数据与支持：存储与清理、高级诊断、关于。

新增设置页时，先放进含义最接近的现有分组。只有出现一组无法归入现有类别的配置时，才新增分组，避免侧边栏越来越碎。

## 主题色

- 侧边栏选中项、主要按钮、快捷面板标签、资料库选中态、置顶背景和内容类型标签都直接读取当前主题色。
- 主题变化要在已经打开的窗口里立即生效，不能要求用户关闭窗口或重启 Pasteory。
- 警告、错误、收藏星标和代码语法等有固定含义的颜色不跟随主题变化。
- “更新 ↓”使用独立的更新语义色，不继承主题 tint；具体配色和升级交互见 [应用更新与发布](UPDATES.md)。

## 按钮布局

- 同一行内的操作按钮尽量靠右排列。左侧留给字段名称、状态说明和帮助文字。
- 一组按钮使用同一个右对齐容器。普通操作放在前面，破坏性操作放在最后，例如“重启 Pasteory”在左，“退出 Pasteory”在右。
- 列表项里的行内操作放在内容末尾。应用名称、图标等信息留在左侧，“移除”等按钮放在右侧。
- `Toggle`、`Picker`、快捷键录制器等表单控件按系统习惯排布，不为了追求右对齐而改变控件结构。
- 需要独占一行的说明文字保持左对齐，不能和按钮挤在同一行。
- 主题色一类需要快速比较的选项可以并排展示，但整组选项仍放在字段名称右侧。当前选中的颜色必须有勾选状态，不能只依赖颜色差异。
- 文件规则第一行选择文件后缀和处理方式，删除按钮固定在最右侧。预设后缀按名称升序排列，每个后缀单独配置；后缀是主信息，已有文件图标和中文类型说明用于辅助识别。也可以新增自定义后缀规则。第二行根据处理方式显示应用选择器或命令输入框。

`SettingsView` 中的独立操作统一通过 `settingsActionRow` 排列。布尔设置统一使用 `SettingsSwitchRow`：名称或说明在左，macOS switch 在右，不使用 checkbox。新增按钮时先判断它是否与左侧信息属于同一行；如果不是，就放进右对齐容器。

## 当前页面

- 通用：主题色、登录时启动、运行状态、重启和退出。
- 打开方式：指定链接浏览器、系统图片预览器、代码编辑器和文件规则。文件规则复用文件图标系统的预设后缀，也支持 `.hap`、`.tar.gz` 等自定义后缀；每条规则只匹配一个后缀，自定义规则优先于同后缀的预设规则。规则可以选择 App，也可以用统一的 bash／zsh 执行命令；命令支持终端窗口和静默执行。静默任务的最近状态和“查看本次命令输出”放在对应规则下方，日志弹窗每 0.5 秒刷新。这里保存的只有文件命令写入 stdout 和 stderr 的内容，不包含 Pasteory App 日志；终端窗口模式的输出只留在终端里。
- 采集与隐私：检测频率、来源详情开关、排除应用。
- 链接解析：网页标题解析、失败记录、兜底规则、正则登录解析、Pasteory WebKit 登录会话和 Chrome 连接。普通网页自动匿名解析；“添加登录解析”只用于需要登录的网站，正则匹配不含协议的 `host + path`，并自动统计和重试当前覆盖的链接。
- 快捷键：全局唤起、空格打开、搜索焦点、`⌘B` 聚合内容、各操作快捷键和恢复默认值。
- 存储与清理：内容统计、本地占用、自动归档、导入和导出备份。
- 高级诊断：辅助功能权限、连接诊断和搜索索引。
- 关于：应用图标、当前版本、产品说明、可用新版本、上次检查时间、“检查更新…”链接和“每天自动检查更新”开关。

## 存储统计

- 内容统计支持“1 天”“7 天”“30 天”“总共”四个范围，默认显示近 7 天。1 天从今天 `00:00` 开始，7 天和 30 天都按本机时区的自然日计算并包含今天。
- 统计对象是仍保存在 Pasteory 中的记录：包含已归档内容，不包含废纸篓。时间归属看最近复制时间，不看首次创建时间。
- 所有范围都使用同一方向的横向堆叠条，不能在单日和多日之间切换横竖方向。每行左边显示日期，中间横条的总长度表示当天条数，条内颜色表示文字、图像、链接、颜色、代码、文件和混合内容的构成，右边直接显示当天条数。
- 1 天显示今天一行，7 天按今天到更早日期显示 7 行，30 天保留全部 30 行但容器只露出最近 7 行，向下滚动查看更早日期；总共显示一行总体数据。
- 图例按所选范围汇总，同时显示类型、条数和比例，不能只靠颜色传达信息。
- 本地占用不跟随时间范围切换，因为数据库和内容寻址附件可能被多条记录共同使用，按日期拆分会得到误导性的结果。
- 本地占用分为数据库、图片与附件、归档、备份、日志和其他。数据库包含 SQLite 主文件、WAL 和 SHM；日志目录是 `~/Library/Application Support/Pasteory/Logs/`，其中 `FileCommands` 只保存文件规则静默执行时的 stdout 和 stderr。“其他”包含缓存、浏览器上下文收件箱和根目录中的零散文件。
- 没有执行过静默文件命令时，日志通常显示为 `0 B`。终端窗口模式的输出和调试构建中的少量进程输出不写入这个目录。
- 总大小使用文件实际分配的磁盘空间，并补充它占本机磁盘容量的比例。各类大小继续使用 `B`、`KB`、`MB`、`GB` 十进制单位并保留一位小数。
- Finder 文件只保存引用时，原文件大小不计入 Pasteory 占用。直接复制后保存到 `Attachments` 的图片或 PDF 计入“图片与附件”。
- 统计在后台读取，设置页先显示加载状态。用户可以点右侧的“重新统计”刷新；执行归档后也要自动重算。

## 代码位置

- `Sources/Pasteory/SettingsView.swift`：设置页结构、按钮布局和各项交互。
- `Sources/Pasteory/LinkResolutionSettingsView.swift`：链接解析设置及其行内操作。
- `Sources/Pasteory/OpenBehaviorSettingsView.swift`：链接、图片、代码和文件的打开方式。
- `Sources/Pasteory/AppSettings.swift`：设置数据与快捷键配置。
- `Sources/Pasteory/SettingsNavigation.swift`：共享页面导航状态。
- `Sources/Pasteory/AppCoordinator.swift`：设置窗口的创建和调试截图入口。

## 验证

使用隔离数据打开设置页截图，不读取真实剪贴板：

```bash
QA_DATA_ROOT=$(mktemp -d /tmp/pasteory-settings-qa.XXXXXX)
arch -arm64 /usr/bin/swift build --arch arm64
.build/arm64-apple-macosx/debug/Pasteory \
  --debug-data-root "$QA_DATA_ROOT" \
  --debug-open-settings \
  --debug-settings-links \
  --debug-link-connections \
  --debug-ui-qa \
  --debug-disable-monitor \
  --debug-disable-hotkey \
  --debug-snapshot-path "$QA_DATA_ROOT/settings.png"
```

截图检查侧边栏分组是否清楚、同行按钮是否靠右、说明文字是否完整，以及切换主题后选中项和内容标签是否同步更新。

检查文件规则时，把 `--debug-settings-links --debug-link-connections` 换成 `--debug-settings-open --debug-settings-file-rules`。隔离设置中会生成一条 App 规则、一条命令规则和一条 `.hap` 自定义后缀规则，用于检查类型图标、后缀优先展示、处理方式切换、命令输入框和说明文字。

再加上 `--debug-file-command-log` 可以直接打开文件静默命令日志弹窗，检查执行状态、stdout／stderr 内容、文字选择和 Finder 入口，并确认文案不会让人误以为这是 Pasteory App 日志。

存储页截图可以把 `--debug-settings-links` 换成 `--debug-settings-storage`，并增加 `--debug-seed`。检查默认是否选中“7 天”、7 根横向堆叠条与图例是否一致、本地占用各项之和是否等于总大小，以及“重新统计”是否位于行尾。再切到 30 天，确认首屏只显示最近 7 行并能向下滚动。
