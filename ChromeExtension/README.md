# Pasteory Web Context

这个扩展只在复制事件发生时读取当前选区。打开 Pasteory 的 Chrome 总开关后，所有网站默认允许采集；如需过滤，在 Chrome 工具栏中打开插件并关闭对应网站。总开关或网站开关关闭时，插件不会遍历 DOM，也不会发送网页内容。

本地开发安装：

1. 在 Pasteory 的“设置 → 高级诊断”中点击“准备 Chrome 插件”。
2. Chrome 打开扩展程序页面后，打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择 Pasteory 为你复制到剪贴板的目录。
4. 回到 Pasteory 的“采集与隐私”打开 Chrome。网站默认全部允许，可在插件弹窗中逐站关闭。
